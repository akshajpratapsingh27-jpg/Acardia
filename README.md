# SmritiSetu + Integrated Experience Branches

This project keeps the SmritiSetu caregiver portal as the main app shell while bringing together the merged experience branches:

- Market Place: a Northeast Indian dish memory game inspired by the Northeast Dish Dash branch.
- Tune With Me: a gentle nature-sound listening game carried over from the wallet-balance-peek branch.
- Shared polish and compatibility improvements needed to keep the merged app running smoothly.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://northeast-dish-dash.lovable.app
